In the first stage of building this site there was only **one page, for testing whether the colours and type worked together**.

I moved that page to the address `/art-direction`,
and turned the first screen into a route that walks through the whole site at once.

| | Stage 1 | Stage 2 |
|---|---|---|
| Number of pages | 1 | 8 |
| Code the browser downloads | 168.6 KB | 173.7 KB |
| Share of the limit I set | 93% | 96% |

"Code the browser downloads" is how much has to come down the wire to open a page.
More of it means a slower page, so I set a limit up front and build only inside it.

Moving the whole menu costs just 5.1 KB of code.
There is 7 KB of room left, and I expect to hit the limit in the next stage.

I did not delete the test page.
It shows why this site ended up in its current shape,
and that record is itself one of the things the site is here to show.
