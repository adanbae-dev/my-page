`<모노레포>` 에 원격이 4개 걸려 있는데, 목록을 `head -2` 로 잘라 보고 **첫 항목을 대상이라 단정해 잘못된 원격에 push** 했다. 실제 주 원격은 다른 곳이었다.

다행히 이미 존재하던 브랜치의 fast-forward 였고(덮어쓰기·분기 없음) 세 곳 SHA가 같아 정합했지만, **목록을 자르고 판단한 게 원인**이다. 원격·브랜치처럼 되돌리기 어려운 대상은 전체 목록을 보고 확정한다.

부수 발견: 그 브랜치의 upstream 이 원격이 아니라 **로컬 `master`** 로 잘못 걸려 있어서 `git status` 가 원격과 무관한 ahead/behind 숫자를 보여준다. 인수 없는 `git push` 가 의도와 다르게 동작할 수 있다.
